# math

Mathematics, one folder per field (`analysis/`, `algebra/`, …); modules are named after the path:
`math.analysis.sequences` for `math/analysis/sequences.vk`. Concepts point to their Lean and Mathlib counterparts,
bridges prove variants of a definition equivalent, paths make lectures and guides.
